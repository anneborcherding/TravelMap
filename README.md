# TravelMap

```text
     /    \/  \/    \
   o . . o . . o . . X
        TRAVELMAP
```

## What is this?

This is your chance to generate your own personalized map showing your travel route! TravelMap will guide you through the necessary steps to end up with an SVG file showing your travel route on a map. You can then use this file to print your own poster! You only have to provide your travel route as a KML file, e.g., exported from Travellerspoint or generated by your favorite AI.

Check the [examples](#examples) to see what the maps can look like! If you'd rather let someone else (me) generate your travel map for you, you can make a request on my [Etsy listing](https://www.etsy.com/de/listing/4627143970/personalized-travel-map-with-your-own).

### Prerequisites

- **Python.** Use Python 3.12, 3.13, or 3.14 to install and run TravelMap.
- **Trip file.** Export your trip as a KML file from the application that you use to record your trip, or let AI generate a `.kml` file based on your stops.
- **Internet access.** You need internet access to download map files and use automatic routing.
- **Optional routing API key.** You only need an OpenRouteService API key if you want TravelMap to calculate routes between your stops. You can also supply your own routes or use straight lines.

## Installation Instructions

Let's get going!

### Download TravelMap

1. Install a supported version of [Python](https://www.python.org/downloads/) (3.12, 3.13, or 3.14).
2. Download or clone TravelMap. Run the following commands in the project's root folder.

### macOS or Linux

1. Check the Python version.

   ```sh
   python3 --version
   ```

   The command must show Python 3.12, 3.13, or 3.14. If it shows a different version, use the command for a supported version, such as `python3.12`.

2. Create the virtual environment.

   ```sh
   python3 -m venv .venv
   ```

3. Install TravelMap. This command downloads the Python packages that TravelMap needs.

   ```sh
   ./.venv/bin/python -m pip install .
   ```

4. Check the installation.

   ```sh
   ./.venv/bin/python -m travelmap doctor
   ```

   A successful check shows **Workspace commands are available.**

### Windows PowerShell

1. Check the Python version. If you installed Python 3.13 or 3.12, replace `py -3.14` in steps 1 and 2 with `py -3.13` or `py -3.12`, respectively.

   ```powershell
   py -3.14 --version
   ```

2. Create the virtual environment.

   ```powershell
   py -3.14 -m venv .venv
   ```

3. Install TravelMap.

   ```powershell
   & '.\.venv\Scripts\python.exe' -m pip install .
   ```

4. Check the installation.

   ```powershell
   & '.\.venv\Scripts\python.exe' -m travelmap doctor
   ```

   A successful check shows **Workspace commands are available.**

### Troubleshooting

| Problem | Action |
| --- | --- |
| The terminal cannot find `python3` or `py`. | Install a supported Python version. Open a new terminal and try again. |
| Ubuntu reports that `venv` or `ensurepip` is missing. | Install the Ubuntu `venv` package for your Python version. Then run the command to create the virtual environment again. |
| The installation command cannot find `pyproject.toml`. | Go to the folder that contains both `README.md` and `pyproject.toml`. Then run the installation command again. |
| The installation command cannot download a Python package. | Check your internet connection. Then run the installation command again. |

## Step-by-Step Guide

Getting to your personal, printable travel map requires some steps. But don't worry, the program will guide you through all of them! The following gives you some more details on the steps, complementing the information given when running the program. If you still have questions or issues after reading this, open an issue in this repo!

### Start TravelMap

Run the command for your system from the same folder that you used to install TravelMap.

**macOS or Linux**

```sh
./.venv/bin/python -m travelmap
```

**Windows PowerShell**

```powershell
& '.\.venv\Scripts\python.exe' -m travelmap
```

Use the arrow keys and **Enter** to select a menu item. If TravelMap shows a numbered menu, enter the number and press **Enter**. Select **Help** for instructions for the current step. Select **Back** to return to the previous screen.

### Step 1. Workspace

A workspace is the working folder for one trip. TravelMap keeps your input files, saved work, and poster in this folder.

1. Select **Workspace** on the start menu.
2. Select **Use the suggested folder** or **Choose another folder**.
3. Check the folder path. Use a separate folder for each trip.
4. Confirm the folder. TravelMap creates the folders for the next steps and writes the default settings to `config.toml`.

### Step 2. Your itinerary

The itinerary is the list of places you visited, in the order you visited them. A stop is one visit to a place. A connection joins two stops in sequence.

1. Copy your `.kml` file to the `input/` folder in the workspace. TravelMap shows the full folder path.
2. Select **Continue**. If TravelMap lists more than one file or trip, select the one to use.
3. Select **View stops and connections** to check the stop order, arrival dates, and transport modes. The transport mode is how you traveled, for example, by car or on foot. This information will be used for the routing calculation later. You can still change it later, so leave it as is if unsure.
4. If necessary, select **Reorder stops**, **Update stop dates**, or **Change transport**. TravelMap saves corrections separately from your original KML file.
5. Select **Accept and continue**.

### Step 3. Map data

TravelMap uses country borders to draw the land outlines. It uses regional OpenStreetMap data to draw the roads and water.

1. Download the **Admin 0 – Countries** ZIP file from [Natural Earth](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/). Keep the ZIP file intact.
2. Copy the ZIP file to the `map-data/` folder in the workspace.
3. Select **Continue** to check the files. If the regional files are missing, TravelMap can suggest regions based on your stops.
4. Open [Geofabrik](https://download.geofabrik.de/). Select the countries or smaller regions that cover your stops and the areas between them.
5. Download the `.osm.pbf` files for those regions. TravelMap asks before preparing map data if any PBF exceeds 512 MiB or the files total more than 1 GiB.
6. Copy the `.osm.pbf` files to `map-data/`.
7. Select **Continue** to prepare the map data. The first preparation can take time. TravelMap shows progress in the terminal.

State and province borders are optional. If you enable them in `config.toml`, also add the [Natural Earth Admin 1 ZIP file](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/) to `map-data/`.

If TravelMap asks for more map data, check the area named in the message. Add the missing file to `map-data/` and select **Recheck map data**.

### Step 4. Routes

TravelMap checks for a route between each pair of consecutive stops. It can use route lines from the itinerary, your own route files, or saved routes. If all routes are ready, select **Continue** to go to **Poster design**.

If a connection needs a route, select one of these actions. If unsure, choose the routing service.

- **Find open routes with routing service.** Select the connections to calculate. Check the start and end coordinates that TravelMap will send to OpenRouteService. Select **Send** if you agree. To get an API key, create a free [HeiGIT account](https://account.heigit.org/), sign in, and create a free Standard API key in the account dashboard. Enter your key when the hidden prompt appears. TravelMap uses the key for the current session. Depending on your stops, the routing service may be unable to find a route for some connections using your selected transport mode. TravelMap will let you retry the failed connections with another mode of transportation. For remote places, trying a walking or cycling route may work better.
- **Supply local route files.** Follow Step 5 to add a route file or to use a line from your itinerary.
- **Use approximate straight lines.** Select the connections to draw as straight lines. Check the selection before you confirm it. A straight line shows the link between stops. It does not show the path that you traveled.

### Step 5. Own routes

Use this optional step to supply the path for a connection. TravelMap offers this step while a connection still needs a route.

1. If the itinerary already contains the route line, go to item 3. Otherwise, export the route as a GeoJSON file from a route application. GeoJSON files can store route lines. Use a file with the `.geojson` or `.json` extension.
2. Copy the file to the `manual-routes/` folder in the workspace.
3. Select **Choose a route file**. If your itinerary already contains the line, select **Use a line from the itinerary** instead.
4. Select the line and the connection it belongs to. Check the stop names and the direction of travel.
5. Confirm the assignment. Repeat this procedure for other routes that you want to add.
6. Select **Continue**. If routes are still missing, return to **Routes** to select another method.

### Step 6. Poster design

TravelMap shows the current poster settings. You can use the default design or customize it. Adding more roads and waterways increases the SVG file size. To preview your poster, start with primary roads and a few waterways. You can add more detail later.

1. Review the title, page size, and map layers.
2. If the settings are correct, go to item 5. To change them, open the `config.toml` file shown on the screen in a plain text editor.
3. Edit the settings you want to change. For example, edit `title` under `[poster]` to change the text on the poster.
4. Save the file. Select **Reload config file** to check and display your changes.
5. Select **Accept and continue** when the settings are correct.

The [settings guide](docs/SETTINGS.md) explains the available settings. The [example file](examples/config.toml) shows their layout.

### Step 7. Export

TravelMap checks the routes, map data, and accepted design before it saves the poster. You do not need to supply any new files at this step.

1. Check the filename on the screen. To change it, select **Change filename**.
2. Select **Export SVG**.
3. If a file with that name exists, select a different name or confirm that you want to replace the file.
4. Open the saved SVG from the `output/` folder. TravelMap shows the full file path after export.

To compare route colors for the same trip, set `route_colors = ["#A33F35", "#3F6F66"]`
in the existing `[style]` section of `config.toml`. TravelMap exports a separate SVG
for each color in one run. Colors assigned to specific transport modes still take precedence
on those segments.

### Stop and continue later

Select **Save and exit** to keep completed work. Copy the resume command that TravelMap shows. To continue later, run that command from the TravelMap installation folder.
